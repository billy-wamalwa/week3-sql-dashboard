# SQL Analysis and Dashboard

## Project Overview

This project demonstrates practical data analysis using SQL, Python, Pandas, SQLite, and Streamlit. It focuses on analysing applicant and internship data to generate meaningful insights into internship completion, hackathon performance, and participant rankings.

The project combines SQL queries with an interactive Streamlit dashboard to make data exploration and performance monitoring easier.

## Objectives

- Analyse applicant and internship records using SQL.

- Evaluate internship completion  rates.

- Compare internship performance across different domains.

- Analyse hackathon scores and identify top-performing interns.

- Identify universities with high-performing interns.

- Develop an interactive dashboard for presenting key findings.

## Tools and Technologies

- Python

- SQL

- SQLite

- Pandas

- Streamlit

- Jupyter Notebook

## Database Structure

The project uses three related tables:

- Applicants – Contains applicant information.

- Interns – Contains internship details, domains, start dates, and completion status.

- Hackathon_scores – Contains intern_ids, scores, and domains.

## Key Analysis Areas

- Internship completion and dropout analysis.

- Completion rates by domain.

- Hackathon performance analysis.

- Intern performance rankings using a leaderboard.

- University performance comparisons.
